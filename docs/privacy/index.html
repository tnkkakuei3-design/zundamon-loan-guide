個人情報の取扱い

このサイトの閲覧・入力情報・外部サイトの利用について。

入力情報について

このサイトには、氏名・電話番号・相談内容などを送信する入力フォームはありません。借入れの申込みや本人確認書類の提出も受け付けていません。

サイトの閲覧

このサイト独自のアクセス解析や、広告配信用のスクリプトは設置していません。

本サイトは GitHub Pages で配信しています。アクセスに伴う情報の取扱いについては、配信サービスのプライバシーに関する案内もご確認ください。

リンク先のサイトや別の窓口で相談・申込みをする際は、送信先の事業者が提示する利用目的と個人情報の取扱いをご確認ください。
