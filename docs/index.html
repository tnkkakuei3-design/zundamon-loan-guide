金利・返済総額

「実質年率」と「毎月の返済額」を確認。ATMなどの手数料を含めて、いくら返すのかを見ておきましょう。

申込条件・受取時間

申込対象・本人確認書類・受付時間を確認。「最短」の時間は、申込状況や審査によって変わります。

電話連絡・郵送物

連絡方法や書類の受取方法も大切。「原則なし」と案内されている場合は、例外の条件まで確認しましょう。

よくある質問

Q.「最短」の時間で、必ず借りられますか？＋

必ず借りられるという意味ではありません。申込時間・審査状況などによって時間がかかる場合があります。対象サービスの公式サイトで、適用条件を確認してください。

Q.このページから申込みできますか？＋

このページでは、借入前の確認ポイントと返済額の目安を確認できます。申込み・審査・契約は、検討している金融会社の公式サイトで行ってください。このページで申込みや個人情報を受け付けることはありません。

Q.試算結果と、実際の返済額は同じですか？＋

同じとは限りません。返済方式、借入日、手数料、端数処理などによって変わります。試算は予算を考えるための目安として使い、契約前に金融会社が示す返済条件を確認してください。

Q.本人確認書類は何が必要ですか？＋

必要な書類は金融会社や申込方法によって異なります。利用できる本人確認書類、住所確認書類、収入を確認する書類の要否を、申込み先の案内で確認してください。

このサイトについて

カードローンを検討するときの確認ポイントと、返済額の概算を案内する情報ページです。特定の金融会社による公式案内、審査結果、融資条件の提示ではありません。

入力情報の取扱い

試算に入力した数値は、ブラウザ内の計算にのみ使います。このサイトから外部に送信したり、入力履歴を保存したりしません。

情報の確認先
