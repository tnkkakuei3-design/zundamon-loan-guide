  4. 04

    契約内容を確認

    返済額や契約条件に同意したうえで契約します。融資は貸付事業者が定める手続きで行われます。

よくある質問

Q.「最短」の時間で、必ず借りられますか？＋

必ず借りられるという意味ではありません。申込時間・審査状況などによって時間がかかる場合があります。対象サービスの公式サイトで、適用条件を確認してください。

Q.このページから申込みできますか？＋

このページでは、借入前の確認事項と相談の流れをご案内しています。申込み・審査・契約は、検討している金融会社の公式サイトで行ってください。このページで申込みや個人情報を受け付けることはありません。

Q.相談しただけで契約になりますか？＋

相談だけで借入契約が成立するものではありません。申込みや契約の前に、金利・返済方法・手数料などを確認してください。

Q.本人確認書類は何が必要ですか？＋

必要な書類は金融会社や申込方法によって異なります。利用できる本人確認書類、住所確認書類、収入を確認する書類の要否を、申込み先の案内で確認してください。
