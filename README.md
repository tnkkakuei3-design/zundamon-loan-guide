# ずんだもんのカードローン案内

広告動画と同じキャラクター素材と黄・緑・白を使ったスマホ向けページ。
ビルド不要。`docs/` が配信対象です。案内ページとFAQはJavaScriptなしで利用できます。

## 現時点の範囲

商品概要の6項目にユーザー指定の条件を掲載しています。数値と返済条件はアイフル公式の商品概要と照合し、表の下に出典を記載しています。貸付事業者、申込対象、申込方法・申込URLは未指定です。
現在の主ボタンは `contact/` の相談窓口ページに接続。申込・個人情報の受付はありません。
貸金業者の公式サイトを装う名称、ロゴ、登録番号、実績、推薦、口コミは使用していません。
GitHub Pagesで案内ページを公開します。実際の広告流入用に仕上げるには、金融会社・商品名、正式な申込リンク、運営者情報を反映してください。
商品情報を入れた際は広告表示・適用条件とFAQも併せて更新してください。

## キャラクター

坂本アヒル氏の立ち絵。NightWork氏のパーツ化素材を既存動画から引継ぎ。
HTML上の透明レイヤー合成。見出しに向かう案内役として配置し、常時アニメーションは使用していません。
商用広告への利用は公式と素材作者の該当する利用条件・必要な許諾を確認すること。確認用の制作は、広告利用の許諾取得を意味しません。
出典は `sources.json` と `character-sources.json`。

## 商品・問い合わせ情報

返済シミュレーターと計算処理を削除しました。商品概要、相談から契約までの一般的な流れ、問い合わせ欄を追加しています。
会社名はRIVIERA。所在地、貸金業登録番号、協会会員番号、貸付事業者、申込対象、申込方法、電話番号、オンライン窓口は未提供のため空欄です。
契約極度額・貸付利率・返済期間と回数・遅延損害金・返済方式・担保と連帯保証人を入力済み。最長返済期間の「500万円を年12.0%で借りた場合」という条件を省略せず掲載しています。
問い合わせ欄の受付時間「24時間」はユーザー指定によります。連絡先は未接続で、個人情報を収集するフォームはありません。

参考サイトの借入可能額チェック・LINE誘導は未導入です。正式な条件と接続先が提供されてから検討してください。
