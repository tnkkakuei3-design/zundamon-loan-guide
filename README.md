# ずんだもんのカードローン案内

広告動画と同じキャラクター素材と黄・緑・白を使ったスマホ向けページ。
ビルド不要。`docs/` が配信対象です。`docs/app.js` が試算とダイアログを制御します。

## 現時点の範囲

金融会社・金融商品・申込URLが未指定のため、商品固有の金利、審査時間、申込対象、融資条件は掲載していません。
現在の主ボタンはページ内の確認項目・返済試算に接続。申込・個人情報の受付はありません。
貸金業者の公式サイトを装う名称、ロゴ、登録番号、実績、推薦、口コミは使用していません。
GitHub Pagesで案内ページを公開します。実際の広告流入用に仕上げるには、金融会社・商品名、正式な申込リンク、運営者情報を反映してください。
商品情報を入れた際は広告表示・適用条件とFAQも併せて更新してください。

## キャラクター

坂本アヒル氏の立ち絵。NightWork氏のパーツ化素材を既存動画から引継ぎ。
HTML上の透明レイヤー合成。見出しに向かう案内役として配置し、常時アニメーションは使用していません。
商用広告への利用は公式と素材作者の該当する利用条件・必要な許諾を確認すること。確認用の制作は、広告利用の許諾取得を意味しません。
出典は `sources.json` と `character-sources.json`。

## 返済額の概算

毎月返済、年利÷12の月利、元利均等返済。各月の利息を1円未満切捨て、通常返済額は1円単位で切上げ、最終回は残高清算。
手数料、日割り利息、無利息期間、追加借入れを含まない一般的な計算例。
入力された数値はブラウザ内のみで計算し、保存・送信しません。

## 検証

`node check.mjs`
主要な試算ケース、ゼロ金利、総額と内訳の一致、最終残高、不正入力、HTMLの参照ファイルとリンク先を確認。
確認範囲は verification.json に記録します。今回、実ブラウザによる画面・操作の確認は未実施です。
